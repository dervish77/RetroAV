RetroAV docs
============

Notes:
- master shield schematic is on EasyEDA.com

- copy of shield schematic EasyEDA project file is "Schematic_RetroAV.json".  This file 
can be loaded into EasyEDA schematic editor by viewing file source of an open project.

- all block diagram master files are the *.drawio files which can be edited online using 
drawio.com or offline by downloading the drawio tool for Windows, Mac, or Linux

- the block diagram PNG files are exported from the drawio tool
